# MangaLens 屏幕实时翻译

在网页上看日文漫画时，自动把对话框里的日文识别出来、翻成中文，并**直接盖回原文所在位置**。
页面本身不会被修改，滚动、缩放、翻页都照常，其它地方一个像素都不会动。

支持常见语言转中文（日语、英语、韩语、法语、德语、西语、俄语、泰语、越南语等），
日文竖排（从右到左的短句）也能识别。

## 快速开始

1. 双击 `install.bat`（只需运行一次，安装识别引擎等依赖）
2. 双击 `run.bat` 启动
3. 打开漫画网页，点控制面板上的 **框选区域**，框住漫画页面（**每次启动都要重新框一次**）
4. 选区周围会出现一圈蓝色描边，提示当前正在翻译的范围

> 框选之后程序**自动开始翻译**。想临时停下时点面板上那个大按钮（**暂停翻译 / 开始翻译**），
> 或按 `F8`；暂停时选区描边仍然保留，方便你随时调整区域。

> 首次使用某个识别引擎时会自动下载模型（几十 MB，需要联网），之后就不用了。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `F9` | 框选翻译区域 |
| `F8` | 开始 / 暂停翻译 |
| `F10` | 全屏 / 区域模式切换 |
| `F7` | 立即重新翻译当前画面 |

## 工作原理

```
定时抓屏 -> 画面是否变化 -> 识别文字 -> 合并成对话框 -> 翻译 -> 抹掉原文并原地排版中文 -> 覆盖层显示
```

- **覆盖层**是一个置顶、点击穿透的透明窗口，不抢焦点、不影响鼠标操作，页面布局完全不受影响。
- **变化检测**：程序知道自己画了什么，会先把"原图 + 我们的译文"算成一张预期图；
  屏幕和预期图一致时完全不动作（静止看漫画时 CPU 接近 0）。
  只有你滚动、翻页、切标签之后才会重新识别。
  具体做法是把"译文盖住的区域"从比较里排除，所以无论系统截图里有没有译文，
  静止时都不会反复重译。
- **翻译缓存**：同一句话只翻译一次，重复内容（包括回看）不再请求网络。
- **排版方向**：日文竖排（从右到左的一列列）会先被读成正确的句子顺序，但**中文按横排画回去**
  （从左到右、从上到下），符合中文阅读习惯。竖排原文的文字框又窄又高，程序会在对话框内部的
  空白里自动向左右借用一点空间，避免横排后字被挤小。

## 引擎选择

### 识别引擎（OCR）

| 引擎 | 说明 |
| --- | --- |
| **RapidOCR**（默认，推荐） | ONNX 模型，体积小、速度快、多语言，模型从 ModelScope 下载，国内直连稳定 |
| Windows OCR | 用系统自带识别，零下载、最快；日语支持取决于系统语言包，竖排日文较弱 |
| manga-ocr | 日漫专用模型，识别质量最好，但首次要下 400MB 模型（走 hf-mirror 镜像），竖排支持一般 |
| PaddleOCR | 可选，本机实测其推理后端与 Paddle 3.3 不兼容（启动即报错），不建议启用 |
| Tesseract | 需要另外安装 tesseract 程序 |

### 翻译引擎

| 引擎 | 说明 |
| --- | --- |
| **MyMemory**（默认） | 免密钥、国内可直连。匿名每天约 5000 字符，在「设置」里填一个邮箱可提升到 5 万字符 |
| 大模型（OpenAI 兼容） | 质量最好，支持 DeepSeek / 智谱 / 通义 / Kimi / 硅基流动 / 本地 Ollama 预设，需要 API Key |
| 本地离线模型 | opus-mt 模型，下载几百 MB 后完全离线、不限量（日语经英文中转） |
| 谷歌翻译 | 需要能访问谷歌（国内需代理），在「设置」里填代理地址 |
| DeepL | 需要 API Key |

> 谷歌翻译在国内无法直连，所以默认没有选它。如果以后能上谷歌，选它即可。

## 使用建议

- **只框住漫画正文**，别把整个浏览器窗口框进去：区域越小越快，也能避开网页上的按钮文字。
- 网页缩放调大一点（漫画文字更大）识别会更准。
- 如果某句话识别错了，可以按 `F7` 手动重试；实在识别不出来时把区域框小一点再试。
- 控制面板可以拖到漫画区域外面，程序会自动避开它所在的区域。

## 设置项

- **开始翻译 / 暂停翻译**（面板上最大的按钮）：总开关。暂停时不再抓屏识别，选区描边保留。
- **检查频率（帧/秒）**：每秒检查几次"屏幕有没有变"，**不是翻译速度**。
  调高只会让翻页后更早开始工作（默认 5 次/秒；静止时几乎不占 CPU）。
- **不透明**：译文覆盖层的不透明度。
- **字号**：译文相对原文的大小，默认自动适配对话框。
- **抹除原文**：勾选时用周围颜色修补（推荐）；取消则用对话框底色直接盖住。
- **文字描边**：给译文加深色/浅色描边，在复杂背景上更清楚。
- **中文横排**（默认勾选）：中文一律横排，不跟随日文竖排；取消勾选则按原文方向排。
- **设置**：配置大模型密钥、MyMemory 邮箱。
- **hide_from_capture**（`config.json` 里手动改）：默认 `false`，截图/录屏能看到译文；
  改成 `true` 时译文不会被任何截图或录屏捕获，适合需要"程序自己的抓屏绝对不含译文"的场合。

## 常见问题

**为什么每次启动都要重新框选区域？** 这是刻意的：选区不写入配置文件，程序启动后不会自动抓屏，
必须由你手动圈定范围后才会开始工作。

**换盘符、换目录后还能用吗？** 可以。程序不依赖自己所在的位置：配置和密钥放在 `%APPDATA%\MangaLens`，
识别模型缓存在 Python 环境里，所以整个文件夹可以放在任何盘符、甚至 U 盘上运行。
反过来，如果同一个程序被复制成两份，它们共用同一份配置。

**选了「大模型」后很慢或者像卡住？** 大模型按整页合并成一次请求（不是每句一次），一般 1~3 秒。
如果几十秒不出译文，状态栏会直接显示原因（密钥无效、余额不足、网络超时、免费额度用尽等），
按 `F7` 可以重试。

**同时开两个程序会怎样？** 现在会自动拦住第二个实例并提示，避免两个覆盖层互相打架、快捷键失效。

**API Key 存在哪？会被别人看到吗？** 见下面的「配置与密钥」。

**翻页后为什么要等几秒才出译文？** 一次更新的耗时大致是：

| 阶段 | 耗时 | 说明 |
| --- | --- | --- |
| 发现画面变化 + 等待稳定 | 约 0.2～0.6 秒 | 受「检查频率」影响，滚动中会一直等 |
| 文字识别（RapidOCR） | 约 0.4～1.1 秒 | 区域越大越慢 |
| 翻译 | 约 2.1～2.4 秒（免密钥接口） | **主要瓶颈**，是免费接口的固定网络耗时 |
| 排版绘制 | 约 0.06 秒 | |

实测：翻页后约 3～4 秒出译文；同一页再次出现（命中翻译缓存）约 1.5 秒。
想更快可以换用「大模型」（一次请求约 1 秒，需要 Key）或「本地离线模型」（无网络往返）。

程序会把整页文字**合并成尽量少的请求**（实测 6 个文本框合并成 1 次请求，比逐条请求快一倍），
所以同样的网络条件下已经把等待压到了接近下限。

**翻译没有出现？** 看控制面板底部状态栏：如果没有框选区域会提示；如果引擎加载失败会显示原因。

**提示额度用完？** MyMemory 免费额度有限，换用「大模型」或「本地离线模型」可无限使用。

**识别不到文字？** 换识别引擎试试（日文推荐 RapidOCR 或 manga-ocr），或把区域框得更贴近漫画。

**日语竖排识别不全？** 系统自带 OCR 对竖排较弱，请用 RapidOCR / manga-ocr。

**配置文件在哪？** `%APPDATA%\MangaLens\config.json`，翻译缓存在同目录的 `cache.sqlite3`。
删掉缓存文件可以强制重新翻译；该目录不可写时会退到 `%LOCALAPPDATA%`。

## 配置与密钥

- 配置存放在 **`%APPDATA%\MangaLens\`**（系统不可写时退到 `%LOCALAPPDATA%`），
  **刻意不使用程序所在目录**，避免整个文件夹被复制/上传时把配置一起带走。
- 大模型和 DeepL 的 **API Key 单独加密存放**在 `secrets.bin`，用的是 Windows 自带的
  DPAPI 加密：密钥和**当前设备的当前用户账号**绑定，把文件拷到别的机器或别的账号下都解不开。
- `config.json` 里不会出现任何密钥；旧版本遗留的明文密钥会在启动时自动搬进加密文件。
- 选区（`region`）和模式（`mode`）不写入配置，每次启动都需要重新圈定。

## 目录结构

```
mangalens/            主程序
  capture.py          屏幕采集
  ocr/                识别后端（rapidocr / windows / manga-ocr / paddleocr / tesseract）
  translate/          翻译后端（mymemory / llm / offline / google / deepl）+ 缓存
  layout.py           把零散文字行合并成对话框，并排好阅读顺序
  compose.py          抹掉原文 + 按框排版中文
  blend.py            透明图层合成（避免半透明区域发暗）
  border.py           选区提示描边
  overlay.py          置顶点击穿透的覆盖层窗口
  pipeline.py         抓屏、变化检测、调度
  config.py / secrets.py  配置读取与 API Key 加密存放
  ui.py / app.py      控制面板
tools/
  setup.py            安装脚本（install.bat 调用它，中文提示在这里输出）
  make_sample.py      生成测试用的模拟漫画页
  probe_ocr.py        对比各识别引擎效果
  probe_translate.py  探测可用的翻译接口
  probe_latency.py    实测翻译接口的延迟结构（并发 vs 合并请求）
tests/
  test_pipeline.py    端到端自检（含"不影响整体布局"校验）
  test_overlay.py     覆盖层自检
  test_live_loop.py   真机循环自检（静止不重复翻译、变化后重新翻译）
```

## 开发者命令

> 说明：`install.bat` / `run.bat` 内部只写 ASCII 字符。批处理是 cmd 按系统代码页解析的，
> 直接写中文（UTF-8）会乱码甚至解析出错，所以中文提示统一由 `tools/setup.py` 输出。

```powershell
python tools\setup.py --skip-pip                # 只做自检
python -m mangalens --doctor                     # 检查环境
python -m mangalens --image a.png --out b.png    # 翻译单张图片，便于调试
python -m mangalens --region 100,100,1200,900    # 启动时直接使用指定区域
python -m mangalens --fullscreen                  # 启动即全屏模式
python tests\test_pipeline.py                    # 端到端自检
python tests\test_live_loop.py                   # 真机循环自检（需抓屏权限）
```
